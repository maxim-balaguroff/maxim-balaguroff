# Maxim Balagurov

English · [Русский](https://github.com/maxim-balaguroff/maxim-balaguroff/blob/main/README.ru.md)

Senior petroleum geologist. Carbonate and clastic reservoirs, from seismic to a model a well can test.

15+ years in petroleum geoscience (since 2010): seismic and structural interpretation, geological modelling, prospect maturation, well placement and drilling support. At CGG, I recommended 30+ wells across 15+ exploration areas; every well drilled since has confirmed the predicted targets.

This account holds small tools and notes from that work, rebuilt on made-up or open numbers. Each one comes with a worked example you can check.

Start with [how-sure](https://github.com/maxim-balaguroff/how-sure). The first tool there is a post-drill look-back: the prediction for each target next to what the bit found, and what that changes in the next recommendation.

I use AI for routine work. The interpretation and the signature on the numbers stay mine.
